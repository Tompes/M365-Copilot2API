# 模型发现、自定义路由与请求测试

在「设置 → 模型发现与自定义路由」管理对外模型列表，无需修改源码。

## 候选发现的范围

点击「同步微软候选项」会从微软网页资源中提取完整的候选 tone 标识，包含新版 GPT、Claude、Grok、Muse 等标识格式。该操作不携带账号令牌。

公开页面可能重定向到登录页，无法自动发现当前脚本版本。此时页面会明确提示使用 2026-11-03 从实际网页观察到的固定版本脚本，并显示完整来源地址和同步时间；这不是始终最新的实时模型目录。可以填写更新的微软 `main.<hash>.js` 地址同步。仅允许指定微软公开 CDN 的 HTTPS 路径，不接受其他主机、查询参数、凭证或重定向。读取失败不会清空上次候选项，也不会把失败报告成成功。

**候选集合不是账号授权列表，不保证完整，也不保证每个标识都能调用。** 网页菜单也不是完整后台目录：它受账号、入口、套餐和灰度影响。「快速响应」「深度思考」属于响应模式，不能仅凭显示名称确定底层型号。

## 自定义与发布

- 上游标识允许输入任意合法的短标识，不再限制为内置枚举。名称只允许字母、数字、点、下划线、连字符；不能填写 URL 或代码。
- 每项可设置公开模型 ID、显示名称、响应模式/模型候选类型、默认推理级别、所有账号/个人 Free/个人 Premium/组织账号范围。
- 「添加自动模式」生成 `copilot-auto → Magic` 路由；它是自动路由，不宣称固定型号。
- 高级场景默认按账号自动决定。显式场景只改变发送给微软的请求上下文，不增加任何账号权限。`OfficeWebPaidCopilot` 可能被个人账号或未获授权的组织账号拒绝。引用社区方案时，必须连同入口/场景一起复测，不能只复制模型名称。
- 点击「添加/更新路由」修改草稿，再点击「保存模型设置」应用。取消发布的自定义路由从 `/v1/models` 隐藏，调用时明确拒绝。
- 勾选「仅发布自定义路由」后，对外列表仅包含已发布的自定义项，不再混入内置猜测目录。未发布的模型请求会被拒绝。
- `/v1/models` 按当前已启用账号的类型过滤范围；请求选择与故障转移也检查账号范围，避免把 Premium 专用配置发给 Free 账号。
- 兼容列表保留 `data` / `models` 两个字段，并附带 `routing_kind`、`account_scope`、`upstream_tone`、`identity_verified:false`。元数据明确区分路由配置与型号证据。

## 指定账号测试

选择账号后可以在保存前测试任意候选 tone 与场景，每次会发送一条 `Reply only OK.` 消息并消耗账号额度。仅收到预期回复时记录「请求成功 · 型号未确认」，空回、错误或其他回复记为失败。

测试按账号、tone 和场景区分，不自动发布路由，不修改账号套餐。服务器目前没有可靠、文档化的实际型号证据，**不会用模型自报身份、普通回复或测试题表现宣称模型版本已验证**。诊断记录仅保留在当前进程内存，重启后清空。自定义路由使用原设置存储机制；免费无持久磁盘部署仍需自行备份配置。
